# Shepema 📖✨

> *Guided by God's Word* — An aesthetic devotional journaling and Scripture reader app crafted with a classic paper notebook aesthetic.

Shepema is a mobile application built with **React Native**, **Expo SDK 54**, and **Expo SQLite**, designed for thoughtful Scripture meditation, structured devotional reflection (R.R.M.A. method), habit tracking, and aesthetic shareable cards.

---

## 🌟 Key Features

- **📖 Scripture Reader**: Complete King James Version (KJV) Bible powered by local SQLite database with fast book/chapter/verse navigation and highlights.
- **✍️ R.R.M.A. Devotional Journaling**: Guided reflection workflow (Rhema, Reflection, Motivation, Application).
- **📅 Daily Dashboard & Streaks**: Habit tracking, today's actionable steps, and devotion streak statistics.
- **🎨 Shareable Cards**: High-res aesthetic quote & devotional image export via `react-native-view-shot`.
- **🔒 Privacy Gate**: Biometric (Face ID / Fingerprint) & PIN security powered by `expo-local-authentication`.
- **📜 Classic Notebook Theme**: Rich typography featuring *Playfair Display*, *Lora*, and *Caveat* with warm paper textures and dark/light modes.

---

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/your-username/rhema-app.git
cd rhema-app

# Install dependencies
npm install

# Start the Expo development server
npm start
```
